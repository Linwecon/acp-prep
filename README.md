# 🎓 ACP 备考助手

阿里云大模型高级工程师认证（ACP – Large Model）一站式备考网站：**知识学习 · 官方实战教程 · 章节刷题 · 标准模考 · AI 答疑 · 跨设备同步**。

打开即用：<https://linwecon.github.io/acp-prep/>

---

## ✨ 网站能做什么

### 📖 知识学习
- 12 章教材式知识点精讲，覆盖官方六大知识域，内置学习目标、现实场景、工作原理、考试重点、常见误区等教材级信息块。
- 逐知识点标记掌握状态，环形进度图实时展示章节完成度。
- 「深度学习 / 考前速记」双模式：考前自动折叠深入讲解，只保留考点与误区。

### 📓 官方实战教程文档
- 阿里云 ACP 官方教程 Notebook（24 篇）按 C1–C5 章节分类在线阅读。
- 按原始顺序完整呈现讲解、代码、运行输出与图片，支持目录导航（默认收起、点开展开）、代码高亮、一键复制、学习进度记录。
- 内容为预先转换的静态网页，浏览器不执行任何 Python；`.ipynb` 源文件可从官方仓库获取：<https://github.com/AlibabaCloudDocs/aliyun_acp_learning>

### 🎯 刷题与模考
- **章节练习**：12 章 2000+ 道题，单选 / 多选，支持全部、未答、错题、收藏四种筛选。
- **模拟考试**：75 题标准卷（50 单选 × 1 分 + 25 多选 × 2 分，及格线 80 分），按官方大纲比例分层抽题，120 分钟计时，交卷后逐题回顾与薄弱章节分析。
- **错题本 / 收藏夹**：错题自动收集、重点题随时标记，支持一键重练。
- **全局搜索**：题干关键词实时检索并高亮跳转；支持键盘操作（A–G 选题、Enter 提交、方向键翻题）。

### 🤖 AI 答疑（可选）
- 调用任意 OpenAI 兼容大模型（阿里云百炼、DeepSeek、智谱、硅基流动等）逐项讲解题目，SSE 流式输出。
- 「题目助手」浮动窗可围绕本题无限追问，携带题干、选项、我的作答与已有讲解作为上下文。
- API Key 仅保存在浏览器本机，浏览器直连服务商，不经过任何服务器。

### ☁️ 跨设备同步（可选）
- 邮箱注册登录后，进度、错题、收藏、成绩、续做位置与教程阅读进度云端同步，冲突按「计数取大、时间戳取新」自动合并。

## 🚀 使用方式

纯前端静态站点，无需安装：直接打开上面的网址即可，也可部署到 GitHub Pages、Cloudflare Pages、Vercel 等任意静态托管。

- 未登录时数据保存在浏览器本地，换设备或清缓存会丢失，建议登录同步；
- 更新后需刷新页面（手机下拉刷新）才能看到最新版；
- 题目与解析以阿里云官方文档与最新考试大纲为准。
