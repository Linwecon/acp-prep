💾
学习进度存本地浏览器（localStorage）：换手机 / 电脑、清除浏览器缓存，进度、错题、收藏会丢失。建议固定一台设备备考，重要进度可截图留存。
⏳
首次打开稍等：题库约 1MB 需下载（页面有加载提示），之后秒开。
🔄
更新后强制刷新：题库更新后，需刷新页面（手机端可下拉刷新 / 清缓存）才能看到新版——GitHub Pages 有缓存。
📖
答案以官方为准：题库是第三方购买 + AI 多模型校验修正的，仍有几十道"模型分歧"题未定论，刷到解析标注"争议"的题，请以阿里云官方文档为准。
☁️
登录与云端同步：右上角用邮箱注册 / 登录。登录后学习进度、错题、收藏、考试成绩会同步到 Supabase 云端，支持跨设备续学；未登录时数据仅保存在本地浏览器，换设备需先登录同步。
🤖
AI 答疑（可选）：答完题后点"AI 答疑"可让大模型讲透本题。需在侧边栏"🤖 AI 设置"填入你自己的 API Key（阿里云百炼 / DeepSeek / 智谱等任选）——浏览器直连调用，Key 仅存本机 localStorage，不上传任何服务器。

🤖 AI 答疑设置

AI 答疑调用你自己的大模型 API Key，在你自己的浏览器里直连， 不经过任何服务器，Key 仅保存在本机 localStorage（可随时清空）。支持多家国产服务商（均为 OpenAI 兼容接口）。

💡 免费方案：硅基流动（注册送免费额度、部分模型长期免费）、智谱 glm-4-flash（免费）、阿里云百炼（新用户免费额度）——均需注册后获取 API Key，无 Key 无法调用。

⚠️ 尚未配置云端同步，请按以下步骤启用登录：

  1. 在 Supabase 新建项目，并在 SQL Editor 执行 supabase/schema.sql；
  2. 在 Authentication → Providers 开启 Email 登录；
  3. 把项目 URL 和 anon public key 填入 config/supabase.js；
  4. 重新部署后即可使用登录与云同步。

（详细步骤见 README「登录与云端同步」。未配置前数据照常保存在本地浏览器。）
